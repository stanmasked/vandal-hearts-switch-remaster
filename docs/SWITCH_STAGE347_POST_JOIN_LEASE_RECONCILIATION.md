# Stage347 — post-join source-only lease balance

[Stage346 independent GCC/Clang + UBSan #39289548088](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39289548088) **passed**, as did its full Host SPU, native PCM, libnx audout and tactical prototype checks. The existing NeXium NRO build succeeded, but the actual NeXium job was still queued.

Stage347 introduces a distinct **post-join audout software ownership receipt** in the Nintendo Switch tactical game. The audio owner now also publishes `lease_pages_released` along with the previously implemented acquisition, busy, mismatch and abandoned-session counters. After the worker joins, a lightweight C11 verifier requires a nonempty, **unsaturated** history with `acquired = released + abandoned-after-full-session-close` and `accepted submitted pages <= released pages`. Only a successful check can produce a canonical, eight-row `scope,value` CSV.

The game writes `audio-lease-reconciliation-000.csv` with exclusive creation after the owner joins. A failed partial optional output is discarded and cannot replace any original Stage307/322 guest-source files. The CSV contains only bounded software counts, no raw PCM, pointer addresses, absolute guest or host timestamps, device playback state, soundtrack or audible sound claims. Adding post-join metadata does not alter SPU, music scenes, audout retry behavior, synthesis, PCM clocks or strict original Stage299–305/334/336 source verification.

The independent Stage347 CI runs GCC and Clang under optimized and UBSan builds. The established Host SPU matrix also compiles and exercises the canonical reconciler. This tests **the software-side accounting rule, not actual guest retrieval**. A future **fresh successful NeXium original run** must export the numbered guest CSV and independently read and validate its original bytes before making a source-level real guest claim. Physical Nintendo Switch speakers, DAC frame delivery and an audible dropout remain untested.
