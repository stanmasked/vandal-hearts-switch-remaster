# MAP02 v110 — Unai native-store continuity at emulator VBlank boundaries

Stacked on [v109 Draft PR #100](https://github.com/stanmasked/vandal-hearts-switch-remaster/pull/100).

The v108/v109 auditors establish event-order VBlank buckets, source Unai
GP0 command families, 24-point readback summaries, native 16-bit store
attempts, same-value stores, and changed-value stores. They do not
preserve the **class-to-class order** within each VBlank interval:
two sequences can have identical per-family histograms while executing
the observed native callbacks in opposite orders.

v110 adds a read-only, strict, independent audit on the *same private*
V104_RENDERER_EVENTS.jsonl generated by the pinned PCSX ReARMed Unai
synthetic emulator:

1. Before each of the four emulator VBlank callbacks, calculate a
   cumulative per-class snapshot of observed Unai callback counts,
   native store attempts, same-value assignments and changed-value
   assignments. Recompute directly from the private event stream.
2. Assert each class snapshot equals the sum of the preceding v109
   VBlank-interval per-class counts. The differences between snapshots
   reconstruct the adjacent VBlank interval's observations.
3. Keep the coarse class of the last Unai callback before each edge and
   first callback after it, if any. Report the number of VBlank edges
   between those two **observed callbacks**, not a CPU/GPU duration.
4. Preserve order-sensitive counts of adjacent Unai class transitions
   *within* each VBlank bucket. Count adjacent handler pairs spanning
   one or more VBlank callbacks separately, and prove conservation of
   all observed pairs.
5. Retain strict four-event handler/readback/store/same-value pairing;
   refuse altered group order, unsupported opcode families, impossible
   native store counts or a VBlank splitting the quartet.

Native GCC/Clang tests use both a five-family multi-VBlank synthetic
stream and a stream with empty adjacent intervals, demonstrate two
handler orders with **identical v109 class histograms but distinct
v110 transitions**, and enforce privacy boundaries.

The pinned v104 full emulator workflow executes v110 against the same
privately stored trace after v108/v109 and writes only sanitized
`proof/public/v110-boundary-class-summary.json`. No raw GPU command
word, VRAM pixel, address, emulator private event stream, synthetic
game code or asset is added to public CI artifacts.

**Timing caveat:** ordering in the host observer is not equivalent
to PS1 CPU-cycle chronology, GPU raster completion, physical display
VBlank, or final MAP02 frame timing. Unai instrumented software
stores do not represent all hardware/renderer/DMA/assembly paths.
