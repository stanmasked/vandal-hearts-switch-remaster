# Stage385 — контроль NeXium TAR до распаковки

**Статус:** **20/20 синтетических тестов успешно**. [Stage385 CI №39488977001](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39488977001) отдельно подтвердил настоящий Linux nightly TAR NeXium до распаковки: 15 элементов (12 файлов), 324150366 байт заявленного содержимого, SHA-256 `c933fbbcf8d1b011de8d4a79c9d8eb55c0678a305947af9388ddb40ce5960a66`. Встроен в Stage371 на этапе скачивания до команды `tar -xzf`; сквозной CI запуска Stage371 ещё требуется подтвердить.

## Назначение

Stage371 скачивает архив NeXium из изменяемого релиза `nightly`. Теперь Stage385 выполняет предварительный аудит **перед распаковкой**, затем Stage384 проверяет сам исполняемый файл и его неизменность между гостевыми сессиями:

- сверяет SHA-256 реально скачанного TAR с метаданными конкретного GitHub release asset, если GitHub публикует digest;
- проверяет точный размер и идентификатор release/asset;
- проверяет имена путей TAR на выход за пределы каталога, запрещает опасные ссылки, дубли, устройства/FIFO и чрезмерный размер распакованных файлов;
- допускает обычные корневые заголовки `./` GNU TAR и безопасные внутренние ссылки;
- создаёт отдельную JSON-квитанцию, не сохраняя бинарный NeXium в репозитории.

В Stage371 проверка **предшествует** `tar -xzf`:

```sh
python3 tools/audit_stage385_nexium_tar_preextract.py \
  --release runtime-evidence/nexium-release-metadata.json \
  --archive /tmp/vh-stage371-nexium.tar.gz \
  --receipt runtime-evidence/nexium-tar-preextract.json
# Только при коде возврата 0 допускается штатная распаковка.
tar -xzf /tmp/vh-stage371-nexium.tar.gz -C /tmp/vh-stage371-nexium
```

Реальный независимый архивный CI подтвердил совместимость Stage385 с текущим NeXium nightly, но поскольку тег `nightly` изменяемый, будущие архивы могут отличаться: их проверка должна оставаться строгой и завершаться отказом при нарушении любого правила. В итоговый артефакт Stage371 добавлена JSON-квитанция; сам архив NeXium не публикуется.

## Проверка

```sh
python3 -m unittest discover -s tests -p 'test_audit_stage385_nexium_tar_preextract.py' -v
```

**Ограничения:** 20 тестов используют искусственные архивы, а отдельный CI проверил текущий настоящий nightly NeXium. Это не гарантирует совместимость с каждым будущим релизом. Одинаковый SHA подтверждает идентичность байтов, но не цифровую подпись. Физическая Nintendo Switch, звук динамиков, HOME/сон и SD **НЕ тестировались**. Оригинальные ROM, PCM, музыка и игровые ресурсы не включены.
