# Stage385 — контроль NeXium TAR до распаковки

**Статус:** локально подготовлено, **19 синтетических тестов успешно**. В GitHub PR №176 Stage385 пока не публиковался: текущий CI Stage384 ещё проходит проверки. На настоящем большом TAR NeXium новый фильтр ещё не испытан.

## Назначение

Сейчас Stage371 скачивает архив NeXium из изменяемого релиза `nightly` и распаковывает его до создания квитанции Stage384. Stage385 добавляет безопасный предварительный аудит:

- сверяет SHA-256 реально скачанного TAR с метаданными конкретного GitHub release asset, если GitHub публикует digest;
- проверяет точный размер и идентификатор release/asset;
- проверяет имена путей TAR на выход за пределы каталога, запрещает опасные ссылки, дубли, устройства/FIFO и чрезмерный размер распакованных файлов;
- допускает обычные корневые заголовки `./` GNU TAR и безопасные внутренние ссылки;
- создаёт отдельную JSON-квитанцию, не сохраняя бинарный NeXium в репозитории.

После интеграции в Stage371 запуск должен **предшествовать** `tar -xzf`:

```sh
python3 tools/audit_stage385_nexium_tar_preextract.py \
  --release runtime-evidence/nexium-release-metadata.json \
  --archive /tmp/vh-stage371-nexium.tar.gz \
  --receipt runtime-evidence/nexium-tar-preextract.json
# Только при коде возврата 0 допускается штатная распаковка.
tar -xzf /tmp/vh-stage371-nexium.tar.gz -C /tmp/vh-stage371-nexium
```

Для интеграции нужны: файл `tools/audit_stage385_nexium_tar_preextract.py`, тест `tests/test_audit_stage385_nexium_tar_preextract.py`, добавление теста в Stage371 и включение JSON-квитанции в список выгружаемых артефактов. Перед публикацией требуется подтвердить совместимость с **настоящим** TAR текущего NeXium. Некоторые законные структуры внутренних ссылок могут потребовать дополнительных проверок.

## Проверка

```sh
python3 -m unittest discover -s tests -p 'test_audit_stage385_nexium_tar_preextract.py' -v
```

**Ограничения:** 19 успешных тестов используют искусственные архивы и не подтверждают работу на настоящем nightly NeXium. Одинаковый SHA подтверждает идентичность байтов, но не цифровую подпись. Физическая Nintendo Switch, звук динамиков, HOME/сон и SD **НЕ тестировались**. Оригинальные ROM, PCM, музыка и игровые ресурсы не включены.
