## Interpretation, limits and next measured experiment

- Published libnx [result.h](https://switchbrew.github.io/libnx/result_8h.html) defines `KernelError_TimedOut` as description 117 within kernel module 1. The exact upstream [audoutWaitPlayFinish implementation](https://github.com/switchbrew/libnx/blob/master/nx/source/services/audout.c) queries released buffers before optionally waiting on a buffer event. The numeric result by itself cannot prove which nested operation returned that kernel status.
- The game emits a **96-frame stereo fade at 48kHz, corresponding to 2 ms of PCM**, then makes **one bounded 12-ms return wait**. The total time until service releases a descriptor depends on queue state and emulator scheduling, and is not provably equal to this 2-ms PCM duration.
- Another completed real [NeXium #39326719578](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39326719578) captured a genuine software **code 7 / raw Result 0** and **1366 acquired / 1366 returned / 0 abandoned**. This demonstrates both successful and kernel-timeout outcomes under the existing nominal 12-ms bound.
- Do not lengthen the exit wait or claim a user-audible problem from these results alone. A controlled separate test with matched queue depth, scheduling and a bounded timeout variant, and later an actual Nintendo Switch audio measurement, is required for that conclusion. The current fail-closed lease policy remains correct on timeout.
