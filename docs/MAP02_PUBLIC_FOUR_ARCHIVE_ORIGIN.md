# MAP02 — происхождение 983 импортов после четырёх системных архивов

## Уже подтверждено GitHub Actions

Исходный публичный PC `ET_REL` из 118 объектов без игровых данных: **520** сильных неопределённых импортов. После действительной `libSDL2.a` — **1085** (493 оригинальных PC-импорта + 592 новых ссылки SDL2). Далее настоящие Ubuntu `libX11.a` и `libxcb.a` в последовательном либо совместном варианте оставили **986**; расширенная настоящая GNU archive group `libX11.a libxcb.a libXau.a libXdmcp.a` оставила **983** (150 входных ссылок разрешено, 48 новых появилось). Все пять проверок PR №368, №380, №385, №389 и №393 завершились успешно (соответственно 30/30, 30/30, 31/31, 31/31, 32/32). Повторные нативные компоновки X11 и XCB подтверждены побайтово.

[PR №368](https://github.com/stanmasked/vandal-hearts-switch-remaster/pull/368) уже установил, что X11 закрывает **150 новых ссылок SDL2** и **ни одной** из 493 первоначальных неразрешённых ссылок PC-кода. Однако нельзя автоматически переносить такое распределение на результат XCB и четырёхархивной группы — необходимо перечитать настоящий итоговый ELF.

## Новая независимая проверка

`tools/check_map02_public_four_archive_import_origin.py` открывает три реальные `ET_REL` через `O_NOFOLLOW` с закрытыми правами 0600 и фиксирует SHA-256, ABI, владельца и inode:

1. Исходный PC ELF с **520** импортами и его приватный манифест.
2. Результат SDL2 с **1085** импортами и его приватный манифест.
3. Выход настоящей группы четырёх архивов — **983** импорта, подтверждённых PR №393.

Сами имена импортов остаются только в памяти локального CI-процесса: внешнему отчёту доступны лишь счётчики и SHA-256. По множествам имён инструмент независимо определяет:

- сколько из **493** первоначальных PC-импортов закрыто четырьмя архивами и сколько осталось;
- сколько из **592** новых SDL2-импортов закрыто и сколько осталось;
- сколько **новых** неопределённых ссылок введено четырьмя архивами (ранее измерено **48**);
- полное арифметическое разбиение **983** итоговых импортов.

Данные сверяются с реальным предыдущим отчётом `libSDL2.a` и результатом четырёхархивной группы. Проверяется, что никакие оригинальные символы не подменены сохранённым манифестом и что файлы не заменены другим inode после чтения. Новые регрессионные тесты используют реальные GNU `cc`, `ar`, `ld -r`, `nm` на синтетическом проекте, включая пример, где четыре архива **действительно закрывают одну исходную PC-ссылку и одну ссылку SDL2**. Это предотвращает ошибку, при которой программа автоматически объявила бы «0 исходных разрешено» без измерения.

## Ограничения

Даже если выяснится, что все 493 исходные PC-импорта сохраняются, это говорит только о конкретных опробованных системных архивах; игра может требовать других оригинальных объектных модулей, внутренних интерфейсов, данных или платформенной реализации. Такой аудит не доказывает работоспособность MAP02 и не создаёт исполняемый PC ELF или `.nro` для Nintendo Switch. Приватные ресурсы пользователя и исходный образ PS1 в GitHub не публикуются.
