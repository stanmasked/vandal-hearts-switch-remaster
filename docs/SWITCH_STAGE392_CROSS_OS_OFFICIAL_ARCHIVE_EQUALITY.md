# Stage392 — воспроизводимое сравнение официальных архивов macOS Intel и Linux

Цель: заменить ручную сверку отчётов Stage390 (PR #370) и Stage391
(PR #371) повторяемой **fail-closed** проверкой в отдельной ветке.
Не вмешиваться в очередь из 19 ожидающих workflows основного Draft PR #176.

Официальные первоначальные workflow:

| Архив | Выполнение | Артефакт | Зафиксированный SHA-256 ZIP |
| --- | --- | --- | --- |
| Intel macOS, Stage390 | [39504403456](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39504403456) | 12302043117 | `0d821384d510449900a3f7b25de8e5fc16bb75534d590a9fad0b9ce393c00d08` |
| Linux x86-64, Stage391 | [39506085942](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39506085942) | 12303775933 | `8e86f6fb370db1d2532704c8e35350ac00362d0253ba3f245f892856d13cca46` |

Каждый ZIP должен содержать ровно один файл
`stage390-twenty-two-original-optical-report.json` длиной **21 078 байт**
и SHA-256 `75c124bce710631ee7469d46159a05b7341382b3135207ffa6f93b30c4b4338d`.
Дополнительно проверяются GitHub metadata оригинального успешного workflow,
принадлежность артефакта исполнению, имя и завершение конкретного job,
CRC ZIP, отсутствие дополнительных/дублирующихся и ссылочных записей,
порядок 11×2 исходных сессий, 22 уникальных оптических источника,
88 переходов и отсутствие потерь. Только после всех проверок проводится
побайтовое сравнение двух исходных JSON.

В `tools/compare_stage392_cross_os_reports.py` и
`tests/test_compare_stage392_cross_os_reports.py` есть 17 синтетических
положительных и отрицательных сценариев: изменение ZIP, подмена run ID,
незавершённый workflow, неуспешный job, чужой репозиторий/артефакт,
лишняя или повторная запись ZIP, дублирование JSON-ключа, неправильные
ожидания и подмена гостевых исходных данных.

В отличие от Stage390/391 эта проверка **не перечитывает одиннадцать
оригинальных источников**: она повторно доказывает только неизменность,
происхождение и точное совпадение опубликованных результатов двух
ранее завершённых независимых аудиторов. Отсутствие ошибки `0xEA01`
в этих исходных отчётах не объясняет историческую причину ошибки.

**Запрет на расширенные выводы:** не запускаются NeXium на Intel Mac,
игровое NRO или физическая Nintendo Switch. Не измеряется звучание,
задержка DAC, корректность HOME/сна либо работа настоящей SD-карты.
