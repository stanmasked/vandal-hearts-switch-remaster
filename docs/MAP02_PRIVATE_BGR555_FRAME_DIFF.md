# MAP02 — локальное сравнение кадров BGR555 (PS1 ↔ PC)

Это инструмент измерения **различий двух необработанных экранных кадров**,
а не средство получения игры, кадров или подтверждения их происхождения.
В публичный GitHub не попадают изображения, ресурсы или пиксели.

## Подготовка данных

Понадобятся независимо полученные пользовательские кадры одного состояния
MAP02: `reference.bgr555` (заявленный PS1-ориентир) и
`candidate.bgr555` (заявленный PC-порт). Каждый файл содержит ровно
`width × height × 2` байт: 16-битные little-endian BGR555-пиксели
без BMP/PNG-заголовков, с битом STP на позиции 15. Перед сравнением
необходимо отдельно убедиться в единой видимой области, ориентации,
моменте захвата, палитре и разрешении. Инструмент **не делает**
масштабирование, выравнивание, цветокоррекцию или догадки о палитре.

В приватном каталоге создаётся `frames.json` вида:

```json
{
  "schema": "vh.map02.private-bgr555-frame-comparison.v1",
  "frame": 411,
  "width": 320,
  "height": 240,
  "pixel_format": "bgr555_le",
  "images": {
    "reference.bgr555": {
      "sha256": "СЮДА_64_СИМВОЛА_SHA256",
      "frame": 411,
      "origin": "ps1_reference_claimed"
    },
    "candidate.bgr555": {
      "sha256": "СЮДА_64_СИМВОЛА_SHA256",
      "frame": 411,
      "origin": "pc_port_candidate_claimed"
    }
  }
}
```

Фактические SHA-256 каждого файла можно вычислить локально командой
`sha256sum`. Числа в примере иллюстративны, не являются данными
реального захвата. Все три файла должны остаться **приватными**.

```sh
python3 -m tools.compare_map02_private_bgr555_frames /private/map02-frame-pair \
  > /private/map02-frame-differential-summary.json
```

Сводка содержит хеши входов и карты различий, число одинаковых и
отличающихся полных 16-битных пикселей, число изменённых строк
и блоков 16×16, количество несовпадений STP, сумму абсолютных
ошибок трёх 5-битных каналов и максимальную ошибку на пиксель.
Она **не содержит** цветов, координат отдельных пикселей,
локальных путей, сырых кадров или авторских игровых ресурсов.

## Что проверяется и что остаётся неизвестным

- Точная длина каждого BGR555-файла, отсутствие символьных ссылок,
  FIFO и повреждённых/меняющихся файлов.
- SHA-256 каждого файла, строго заданный формат и одинаковый номер
  кадра. Пропущенные и лишние поля, дубли JSON и ложные типы отклоняются.
- Различие STP-бита считается отдельно от ошибки цветовых каналов:
  пиксель, отличающийся только STP, всё равно считается несовпадающим.
- Хеш карты различий не раскрывает положения отдельных пикселей.
- Метки `ps1_reference_claimed` / `pc_port_candidate_claimed`
  являются **утверждениями оператора**, не аттестацией эмулятора или
  оригинальной PlayStation.
- Даже **ноль различий** не доказывает розничное происхождение кадров,
  полную аутентичность игры, временную согласованность VRAM или
  эквивалентность GPU PlayStation. Для такого утверждения нужны
  независимые свидетельства процесса, игровых ресурсов и захвата.

CI запускает только синтетические маленькие кадры, включая тесты
STP, ошибок каналов, подмены SHA-256, неверных размеров и путей.
Реальных PS1/PC кадров в CI нет. HD-подмена остаётся запрещённой.
