# MAP02 — побайтовое повторение компоновки X11

Проверяемый сценарий GitHub Actions использует **публично доступный оригинальный PC-код** без игровых ресурсов и системные статические библиотеки Ubuntu.

Подтверждено на предыдущих этапах:

| Стадия | Сильных неразрешённых импортов |
| --- | ---: |
| Первоначальный `ET_REL` из 85 игровых и 33 backend/observer объектов | 520 |
| После GNU `ld -r` с `libSDL2.a` | 1085 |
| После последующего GNU `ld -r` с `libX11.a` | 996 |

На последнем этапе X11 разрешила **150** импортов входящего ELF, но ввела **61** новую ссылку: `1085 - 150 + 61 = 996`. Это подтверждено [Actions №39501428111](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39501428111) — 29 успешных шагов.

## Новый контроль

`tools/verify_map02_public_x11_native_replay.py` принимает только:

1. закрытый манифест имён неопределённых символов, полученный **после SDL2**;
2. закрытый входной ELF из этапа SDL2;
3. ранее скопированную, проверенную системную `libX11.a`;
4. сохранённый результат X11 `ld -r`;
5. JSON с **агрегированными** показателями первого X11-прогона;
6. новый, ещё не существующий каталог для повторения.

Инструмент сначала читает каждый файл через защищённый от символьных ссылок дескриптор с проверкой владельца, прав `0600`, inode, ABI и SHA-256; сверяет настоящие результаты `nm -u` с закрытым манифестом и исходными числами. Затем запускает **второй настоящий GNU `ld -r`**, используя **тот же входной ELF и тот же архив**, но новый приватный каталог `0700`. Результат обязан побайтово совпасть по SHA-256 с сохранённым выходным ELF.

Проверяются не только одинаковые конечные 996, но и исходные 1085, реально разрешённые 150 и новые 61. Отдельный негативный тест подменяет результат X11 *корректным* ELF, сохраняющим число неразрешённых символов, и синхронно обновляет SHA-256 сохранённого JSON. Такой набор внутренне согласованных файлов **не должен** пройти второй реальный `ld -r`.

**Логи CI содержат только агрегаты и SHA-256.** Никакие имена оригинальных импортов, файлы образа игры или приватные ресурсы не загружаются в GitHub. Даже полностью успешный повтор доказывает лишь воспроизводимость частичного `ET_REL` в одном Linux/toolchain окружении: ни полная исполняемая PC-сборка, ни подлинное выполнение MAP02, ни Nintendo Switch этим не подтверждаются.
