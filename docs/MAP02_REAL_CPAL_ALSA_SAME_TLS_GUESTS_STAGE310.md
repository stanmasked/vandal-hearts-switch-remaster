### What can be directly established

The Stage310 source auditor refuses runs unless the **exact new ELF** and unchanged ROM-free NRO match the manifests, the preflight synthetic same-TLS test succeeds, the original CPAL P/L source re-parses independently, both ALSA and tagged-CPAL timestamp sources contain identical sample instants and nonregressing bounded counts, and actual guest first-input/final-observation markers are covered by source samples. A single anonymous TLS alias with **positive CPAL callback marks and positive ALSA exported-call counts in the same guest window** is a direct per-process **same native execution-thread observation** (the same `__thread` storage); an alias with only ALSA calls is a separate execution thread. Zero markers cannot prove absence of a callback if the source pre-resolved hook failed, and the source report explicitly flags this possibility. The report does **not force any 21ms/22ms behavioral difference**.
