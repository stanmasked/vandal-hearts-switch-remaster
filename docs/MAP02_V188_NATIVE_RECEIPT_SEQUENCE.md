# MAP02 v188 — strict sequence audit of pinned native PCSX RAM receipts

Base: [MAP02 v187 Draft PR #217](https://github.com/stanmasked/vandal-hearts-switch-remaster/pull/217), adding exact numeric RAM word snapshots at three genuine native PCSX VBlank boundaries. v187 native CI checks for expected lines using grep, which can establish their presence but not reject duplicate, extra or reordered records in the same process log.

v188 adds an independent, read-only Python checker, run on the actual ten per-process private synthetic guest PCSX ReARMed/Unai logs generated by the existing pinned GCC/Clang native workflow. The checker expects exactly one phase-zero native VBlank before the phase-one pre-execution RAM snapshot; subsequent snapshots must alternate with the observed native VBlank events without missing or repeated phases. Native reports must include the exact frame/event relationship, non-zero bounded interpreter wait loops and absolute snapshot VBlank ordinal.

Mode 0 must contain three intact RAM snapshots and four genuine native VBlank events followed by exactly one each v187, v185, v183 and v176 pass marker. Modes 1-3 must show one bad snapshot at phase one; modes 4-6 two snapshots with the second bad at phase two; modes 7-9 three snapshots with the third bad at phase three. Each failed snapshot must differ by exactly the designated one-bit host mutation (first, derived or guard). Each bad mode must contain one precise RAM REFUSED marker and no positive RAM or Unai marker. The native shell workflow continues to prove process exit 86 independently.

Expected receipt counts: 10 isolated process logs, 21 exact numeric RAM snapshots, 22 observed genuine native VBlank markers, 9 intentional host-only bit flips, all checked independently on GCC and Clang. The checker rejects symlinks and oversized logs to avoid readback from uncontrolled paths and never emits a pass if any expected record is missing, malformed, duplicated or reordered.

No original Vandal Hearts MAP02 scene has been executed by this diagnostic; none of the native checks assert physical Nintendo Switch pixels or finished gameplay. All guest assets remain synthetic and private logs are not committed to GitHub.
