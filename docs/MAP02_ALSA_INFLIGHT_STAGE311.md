## Instruments and precise constraints

Stage311 does **not** compile another NeXium ELF. The new separate ALSA `LD_PRELOAD` userspace diagnostic shim maintains all original Stage308 9 exported PCM function return-class counters and the exact same anonymous `__thread` CPAL marker counter at mmap offset 32768. It adds a bounded new region at offset 33792 with 64 anonymous TLS slots × 13 functions × 3 relaxed atomic uint64 counters (entry, return, negative-return). The original nine exported wrappers plus `snd_pcm_wait`, `snd_pcm_avail`, `snd_pcm_avail_update`, `snd_pcm_poll_descriptors` are wrapped and forwarded to the real function with unchanged arguments/return value. This is *userspace exported symbol coverage only*, not all hidden/internal ALSA calls or direct function-pointer dispatch.

No extra CPAL callback work is introduced beyond the already-validated Stage309 marker. The ALSA wrappers increment counters before/after the call; they do not acquire a lock, write to a file, log a raw pointer, store PID/TID, or call a monotonic clock. A separate non-real-time Python observer reads the 13-function phases, original ALSA successful/error-return counters, and original Stage308 CPAL marker from the *same private mmap at a single* ~200ms monotonic snapshot marker. Three separate sanitized source CSVs retain the same sample timestamp. The private original mmap, raw PCM, GUI FileLogger and PulseAudio private log are never uploaded.

A new Stage311 auditor requires the original Stage310 genuine new-host/old-generated-NRO provenance and P/L CPAL guest source **to be independently reparsed**, plus all three source CSV streams with identical sampling timestamps. It reports for each anonymous TLS alias and exported ALSA function: differences between latest complete sampled counter values before the guest's first input and last observation; number of sampled instants with more entries than returns; peak and last sampled in-flight counts, and whether this TLS alias also received an actual CPAL callback marker in the bounded window. Samples and relaxed atomics are not a transaction. In-flight at one sample instant may simply reflect a normal, finite poll/wait or a read while a call is in progress. **No observed in-flight counter, even on multiple sample ticks, is sufficient to call it a permanent deadlock.** An absence of CPAL marker at 21ms does not establish which native worker should have invoked it.

Stage310's prior 21/22ms behavior is a historical control; the extra instrumented exported calls can perturb scheduling and may change it. This run must not assert exactly zero vs positive CPAL callbacks; if a different outcome occurs, report actual values truthfully. 21ms and 22ms are requested Pulse hint values, not hardware period measurements. There is no original PS1 ROM, licensed music, Switch physical DAC/speaker, native production-game rewrite, proved ALSA root cause or audio repair in these experiments.
