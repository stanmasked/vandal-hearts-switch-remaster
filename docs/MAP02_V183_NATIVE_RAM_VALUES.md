# MAP02 v183 — real guest RAM values, not only access provenance

The prior [v182 Draft PR #211](https://github.com/stanmasked/vandal-hearts-switch-remaster/pull/211) passed 75/75 GitHub Actions, including real pinned PCSX ReARMed/Unai GCC and Clang interpreter tests. Those tests proved matching MIPS word instructions, PC, physical RAM addresses, read/write direction and strict wrong-case refusal; **they did not prove that reading RAM returned the right data**.

v183 introduces a signed **nine-instruction self-authored MIPS-I wait-pad sequence** in the same tagged `VH78SYN!` PS-X EXE: set a scratch base at physical `0x001e0000`, form nonzero `0x51a7c3d9`, guest `SW` it into RAM, deliberately overwrite the source register with `0x000000ff`, guest `LW` from that RAM address, execute a mandatory load-delay NOP, transform with XORI `0xffff`, and guest `SW` the derived `0x51a73c26` to scratch base+4. Only nine originally zero wait instructions are changed; the other source-authored GPU stages, VBlank waits, and Unai pixel expectations are retained.

The new native diagnostic option seeds **different** values (`0x1478295a`, `0xd15ea5ed`) into scratch RAM **in the isolated emulator test** before each VBlank, then requires `psxMemRead32` to return both exact *guest-computed* results after executing the real interpreted wait block. This is deliberate host-owned test fixture setup, not GPU or VBlank injection or a claim that only guest code touched RAM. A missing first guest `SW` or missing guest `LW` must exit **85** in the first phase before any pixel PASS marker. Both negatives are themselves signed EXEs, each with only the corresponding one-instruction NOP mutation within the nine-instruction sequence.

Positive success additionally requires four distinct genuine emulator-internal VBlank events, unchanged GPU quiet-observer results, and 2380 native Unai pixel samples. Independent Python tests check the exact nine MIPS words, MIPS load-delay dependency, both negative variants, the two final values, and failure-closed native CI conditions. The tests use synthetic data only: **no retail Vandal Hearts MAP02 frame, no physical Switch output, no finished remake claim**.
