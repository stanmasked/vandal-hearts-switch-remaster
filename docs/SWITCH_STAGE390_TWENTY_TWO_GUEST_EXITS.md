# Stage390 — оригинальные 22 аудиосессии NeXium, macOS Intel

**Цель:** повторно открыть все 11 оригинальных архивов гостевых
испытаний NeXium в независимом CI на macOS Intel x86-64 и Python 3.9.
Это архивный Python-аудит; ни игра, ни эмулятор NeXium на Mac не запускаются.

Предыдущий Stage386 сверил 20 оригинальных аудиосессий. Stage390
добавляет 11-ю пару из [GitHub Actions №39494326413](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39494326413),
артефакт **№12301225369**, исходный SHA-256 ZIP:
`4ab098139a718e250e1d43520c8a7041ef86ac1ea68b4bbcaeb635836b528710`.

Оригинальный head — `9c2d566a1d8e0762b4fd9bf89aeffd5dc0a597c1`,
гостевой merge — `542e5461ef026f17117d9cc6f43be444e869a6d0`.
Оба исходных программных выхода вернули `audoutWaitPlayFinish=0`,
по одному точно возвращённому дескриптору и сбалансированные PCM-страницы.

Аудитор проверяет происхождение каждой исходной серии через GitHub
run/job/artifact/merge metadata, исходные CSV/PNG, SHA-256 и CRC пакетов,
полные музыкальные переходы и состояние PCM. Также сверяется SHA-256
фактически использованного NeXium в десятой и одиннадцатой сериях.
Эти две версии идентичны побайтово, но **относительно первых девяти
серий такого доказательства нет**.

Ожидаемая проверяемая сводка: **22** оригинальные сессии, **22**
уникальных оптических пакета, **88** музыкальных переходов,
**0** потерянных событий, **20** различных CSV хешей программных
счётчиков. Совпадение CSV счётчиков в некоторых сессиях допустимо,
если их источник отдельно доказан; оптические пакеты должны различаться.

Для локальных синтетических тестов:

```sh
python3 -m unittest discover -s tests \
  -p 'test_audit_stage390_twenty_two_original_optical.py' -v
```

**Границы:** 12-мс ограничение ожидания и PCM-владение в игровом
NRO не меняются; новые гостевые запуски не создаются. Отчёт
не устанавливает причину исторической ошибки `0xEA01`, а также
не доказывает слышимость на физической Nintendo Switch,
работу HOME/сна, чтение/запись настоящей SD-карты или
работоспособность NeXium под macOS.
