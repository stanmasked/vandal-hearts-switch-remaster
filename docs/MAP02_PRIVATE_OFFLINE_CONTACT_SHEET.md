# MAP02 — автономный локальный просмотр трёх кадров

Это следующий шаг после Draft PR #429. До сих пор инструменты
проверяли исходный BK2, журнал захвата, PNG и численные различия
между кадрами. Теперь есть **обычный офлайн HTML-лист**, который
показывает три изображения каждого выбранного интервала рядом.

Лист не содержит JavaScript, внешних картинок, веб-ссылок, аналитики
или сетевых запросов. Исходные PNG остаются в той же **локальной**
папке, на которую HTML ссылается по относительным именам файлов.

## Локальное использование

Нужны оригинальный BK2, локальный журнал BizHawk/Octoshock и PNG из
предыдущих приватных этапов. Всё должно находиться **вне GitHub**.

Команда выполняется на компьютере владельца после захвата изображений:

    umask 077
    python3 -m tools.map02_private_offline_contact_sheet \
      /private/vandalhearts.bk2 \
      /private/vh-map02-review-plan.txt \
      /private/vh-map02-console.log \
      /private/vh-map02-review-png \
      --private-html-output /private/vh-map02-review-png/contact-sheet.html

Затем можно открыть файл contact-sheet.html локально в браузере.
Для каждой группы он показывает:
- Изображение перед периодом без нажатий.
- Изображение в середине периода.
- Изображение после периода, рядом с ориентировочными индексами
  ввода BK2 и числовыми метриками изменения RGB.

Интервалы упорядочены по доле изменившихся пикселей; это **не**
вероятность MAP02. Дизайн адаптируется к ширине окна и к печати.
У HTML нет сценариев, веб-ресурсов или форм отправки. Политика
Content Security Policy запрещает загрузку скриптов и сетевые
подключения. PNG берутся из той же локальной директории.

**Защита приватности:** программа сначала вызывает полный проверяющий
механизм исходный BK2 → план кадров → Lua-журнал → CRC/zlib PNG →
декодированные RGB-пиксели из PR #424/#427. Если данные неполны или
фальсифицированы в пределах выполняемых проверок, HTML не создаётся.
HTML сохраняется только под новым именем с правами 0600, строго
рядом с PNG и за пределами Git-каталога. Перезапись, символическая
ссылка на целевой HTML и относительный путь недопустимы.

## Что требуется оценить визуально

Посмотрите, различаются ли реальные сцены на фотографиях; встречается
ли узнаваемая тактическая карта, интерфейс расстановки отряда, другое
поле боя или экран перехода. Если возникнет кандидат MAP02, сам этот
факт требует дальнейшего независимого подтверждения по состоянию
исходной игры, а затем сверки с моделью GPU/VRAM. Колебания пикселей
могут объясняться курсором, фильтром, меню, заставкой или анимацией.

Учитывайте, что emu.framecount()-1 — пока лишь предположение о связи
ввода и изображённого момента. Отображаемый кадр может запаздывать.

**Никакого автоматического подтверждения MAP02, реального запуска
Octoshock, синхронизации кадров либо GPU/VRAM данный инструмент
не заявляет.** Он только создаёт удобное наглядное представление
локальных файлов для человека.

Не публикуйте HTML: он включает имена приватных PNG и индексы ввода.
Не загружайте BK2, игровой диск/BIOS, журнал и фотографии в публичный
GitHub либо GitHub Actions. Все CI-тесты используют фиктивные координаты
и искусственный HTML без настоящих игровых материалов.
