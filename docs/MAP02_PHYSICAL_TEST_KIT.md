# MAP02 — пакет для испытания на физической Nintendo Switch

Это пакет **для будущего ручного тестирования**, а не подтверждение работы на настоящей консоли.

GitHub Actions собирает лишь самостоятельно написанный asset-free homebrew `vandal-hearts-prototype.nro`. Скрипт `tools/prepare_map02_hardware_kit.py` принимает его только при точном SHA-256:

`564c29e4c6c47eaf80e356733b8bdb8e298f1e0c938575b20be0ae9d48680539`

В итоговом артефакте `map02-physical-console-test-kit-unverified` содержатся:

- `vandal-hearts-prototype.nro` — 155 704 байта, без оригинальных PlayStation-ресурсов;
- `SHA256SUMS` — контрольная сумма;
- `physical_test_manifest.json` — форма отчёта с 17 пунктами, все помечены `not_tested`, а `physical_switch_validated: false`.

Эта форма создана намеренно **без** персональных идентификаторов устройства, ключей и приватных данных. Отдельный валидатор отклоняет модификации NRO и попытки выдать ещё не выполненное испытание за успешное. После фактической проверки результаты фиксируются отдельно, не подменяя автоматически выданную исходную квитанцию.

## Инструкция для оператора

На законно подготовленной для домашнего ПО консоли владелец самостоятельно сверяет SHA-256, размещает NRO в поддерживаемом homebrew-каталоге на SD и запускает через штатный homebrew-лаунчер. Не следует модифицировать системные файлы или выкладывать содержимое личной консоли.

Проверки: запуск; MINUS для старых карт; ZR для опционального режима; L/R переключения; выстрел лучника; защита; лечение; победа и поражение; Y-сброс; возвращение в старую карту; PLUS-выход; сон/возобновление; изображение в портативном и док-режиме (если доступен).

Для каждого пункта фиксируют `pass`, `fail`, `skipped`, название режима и краткое описание отклонений **только после реального испытания**. Версия прошивки, способ запуска и особенности управления должны быть указаны без серийного номера и секретов.

**Граница результата:** доказаны сборка NRO и её эмуляторные сценарии NeXium, но не физический запуск. Этот Draft PR не меняет `main`, не сливает уже утверждённые PR и не распространяет коммерческую игру.
