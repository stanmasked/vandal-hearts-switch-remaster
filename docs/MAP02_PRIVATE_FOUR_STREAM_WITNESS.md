# MAP02 — приватное итоговое свидетельство GPU/GTE/PutPixel/BlendG1/VRAM

Этот этап объединяет **только структурно проверенные** файлы одного
выбранного GPU-кадра оригинального PC-порта. Исходные данные игры, 
снимки VRAM и сырые события остаются в отдельных приватных каталогах.
Ни одна команда ниже не загружает данные в GitHub и не печатает
исходные пиксели.

## Необходимые данные

Прежде чем публиковать итоговый манифест, должны существовать три
**разные** приватные папки с правами владельца (0700):

- `/private/map02/source-bundle` — исходные MAP02/GTE-свидетельства,
  пользовательский SHA-claim о соответствии часов игрового и GPU-кадров,
  **уже опубликованный**
  `gpu-native-window-source-witness.json`. Этот промежуточный
  манифест должен пройти реальную проверку
  `verify_published_window_source_witness` с компиляцией GTE;
- `/private/map02/native-windows` — полные исходные VRAM-снимки,
  `gpu-native-window-index.json` и последовательные
  `window-000` / `window-001`;
- `/private/map02/scoped` — три **закрытых, но ещё не продвинутых**
  журнала выбранного пикселя:
  `putpixel-native-events.pending.jsonl`,
  `blendg1-native-events.pending.jsonl` и
  `vram-edges-native-events.pending.jsonl`.

Исходный комплект **не заменяется** фальшивыми данными или манифестом,
созданным из самих окон. Он верифицируется отдельным GTE/FT4-конвейером.
Номера `source_frame` и `gpu_draw_frame` не обязаны совпадать, их
связь явно определяется отдельно предоставленным source claim.

## Проверить и опубликовать

```sh
# 1. Повторная проверка исходного FT4/GTE/OT и всего дерева окон
python3 -m tools.publish_map02_native_window_source_witness \
  /private/map02/source-bundle /private/map02/native-windows

# 2. Проверка всех потоков вместе БЕЗ публикации
python3 -m tools.verify_map02_window_scoped_join \
  /private/map02/native-windows /private/map02/scoped \
  --frame <фактический-номер-GPU-кадра> \
  --source-bundle /private/map02/source-bundle

# 3. Исключительная публикация итогового манифеста (один раз)
python3 -m tools.publish_map02_window_scoped_witness \
  /private/map02/source-bundle /private/map02/native-windows \
  /private/map02/scoped \
  --frame <фактический-номер-GPU-кадра> --publish

# 4. Повторная независимая полная проверка готового манифеста
python3 -m tools.publish_map02_window_scoped_witness \
  /private/map02/source-bundle /private/map02/native-windows \
  /private/map02/scoped \
  --frame <фактический-номер-GPU-кадра>
```

Число GPU-кадра нужно узнать из **реального** приватного захвата.
Не следует подставлять номер кадра из синтетического примера.

Итоговый приватный файл:
`source-bundle/gpu-native-window-scoped-source-witness.json`.
Он создаётся с разрешениями **0600**, только если отсутствует
предыдущее имя. Любая ошибка до публикации оставляет завершённый
манифест отсутствующим. Повторное выполнение с `--publish`
**не перезаписывает** уже сохранённый файл.

## Защита целостности

Публикация проверяет и связывает SHA-256:

1. отдельно опубликованного источниково-привязанного GTE/FT4-свидетельства;
2. **всего содержимого** последовательных окон GPU, включая полные
   снимки VRAM, журнал команд и загруженные слова текстур;
3. отдельно наблюдавшихся событий PutPixel;
4. настоящих вызовов BlendG1;
5. напрямую считанных значений VRAM до/после каждого примитива DrawOTag.

Прежде чем создать итоговый файл, инструмент повторяет дорогую проверку
всех этих данных, сравнивает её с первым результатом, затем выполняет
исключительную публикацию и контролирует байты записанного манифеста.
При повторной проверке заново запускается весь конвейер и сравниваются
все хеши и счётчики.

Коды диагностики отвергают неоднозначные FT4, несогласованные
глобальные номера, пропущенные примитивы, разрыв полной VRAM между
окнами, изменение выбранного пикселя и ложный признак прохождения GTE.
Вместе с тем совпадение SHA-256 **само по себе не доказывает**, что
трассы получены из одного настоящего игрового выполнения: важно
дополнительно документировать процедуру захвата и происхождение
исходного игрового материала.

## Подтверждение в CI

[Успешный запуск GitHub Actions, 118/118 тестов](https://github.com/stanmasked/vandal-hearts-switch-remaster/actions/runs/39024583871)
подтверждает синтетические позитивные и негативные тесты,
безопасность публикации и выполнение настоящих модулей
`libgpu.c`/`pc_raster.c`.

В синтетических unit-тестах **только проверка исходного GTE**
может быть заменена явной тестовой заглушкой. В рабочем коде она
необязательной не становится.

Ни один завершённый манифест до сих пор не подтверждает
оригинальную игровую сцену MAP02, полноту всех кадров игры или
эквивалентность физическому GPU PlayStation. HD-подмена остаётся
**отключённой** до независимой проверки оригинальной MAP02.
