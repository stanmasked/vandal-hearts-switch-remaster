# MAP02 — непрерывное тактическое испытание в NeXium

Это испытание предназначено только для самостоятельно разработанного, свободного от оригинальных игровых ресурсов прототипа Nintendo Switch. Оно **не** подтверждает восстановление оригинальных боёв Vandal Hearts на PlayStation и не заменяет запуск на физической Switch.

## Что меняется

Ранее лучник, медик и защита отряда проходили собственные реальные сценарии NeXium независимо. Теперь `tests/run_map02_nexium_single_session.py` проверяет их **в рамках одного запуска исполняемой программы**, с последовательными действиями виртуального контроллера и сохранением каждого подлинного кадра.

В одном процессе выполняются:

1. Исходная MAP02 → первая расширенная арена → вторая арена 4×4.
2. Лучник пытается стрелять вне дальности: противник остаётся жив, выделение не пропадает.
3. Лучник перемещается, противник приближается настоящим ходом ИИ, выстрел с двух клеток уничтожает одного врага; остальные живы.
4. Сброс Y восстанавливает арену в исходном состоянии.
5. Три реальных хода ИИ подводят противника; защитник использует A+B, четвёртая фаза уменьшает урон первого удара и меняет состояние индикатора защиты.
6. Медик лечит того же раненого бойца кнопкой B **без сброса между защитой и лечением**.
7. Повторный сброс восстанавливает арену, затем R последовательно переводит составы в 3×3, 1×4 и назад 4×4, проверяя отсутствие невидимых дополнительных бойцов.
8. L возвращает первую расширенную арену; L+R — исходный режим MAP02. Снимки после возврата должны побайтово совпасть по игровому полю с исходными.

Запрещены прямое изменение HP, внедрение состояний в память игры, подмена кадров или повторный запуск эмулятора между способностями.

## Автоматические проверки

- `tests/test_map02_single_session_oracle.py` создаёт только синтетические кадры для проверки чувствительности анализатора к ошибкам. Это **не доказательство** настоящего исполнения NRO.
- `.github/workflows/map02-single-session.yml` сначала проводит отрицательные тесты, затем создаёт реальный NRO через devkitPro/libnx.
- Проверяется точный SHA-256 уже прошедшего NeXium бинарника `564c29e4c6c47eaf80e356733b8bdb8e298f1e0c938575b20be0ae9d48680539`; при отличии результат прежних испытаний не переносится на новую сборку.
- NRO и квитанция SHA-256 связываются с текущим коммитом Git и загружаются вместе; перед стартом NeXium квитанция проверяется повторно.
- Только после этого запускается один настоящий процесс NeXium, создающий 17 кадров, журнал контроллера и отчёт `VH_MAP02_NEXIUM_SINGLE_SESSION_PASS`.

Этот тест повышает уверенность в отсутствии ошибок переключения состояний между способностями. Его успешное выполнение не означает успешного запуска на физической Nintendo Switch. Существующие Draft PR, исходные две карты, приватные игровые образы и ветка `main` не изменяются.
